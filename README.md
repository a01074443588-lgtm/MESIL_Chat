# MESIL Chat

MESIL Chat은 요양 현장에서 흩어지는 대화·사진·문서·음성을 한곳에서 확인하고, 직원이 근거를 검토한 뒤 기록으로 정리하도록 돕는 협업 도구입니다.

- 공개 서비스: [chat.silvermedical.kr](https://chat.silvermedical.kr)
- 공식 소스 저장소: [a01074443588-lgtm/MESIL_Chat](https://github.com/a01074443588-lgtm/MESIL_Chat)

이 공개본의 설명과 검증은 실제 직원·수급자 자료가 아닌 합성 자료를 기준으로 합니다.

## 해결하려는 현장 문제

돌봄 현장에서는 관찰 내용이 채팅, 사진, 문서, 음성 메모에 흩어져 이전 상황과 후속조치를 함께 보기 어렵습니다. MESIL Chat은 원문을 없애지 않고 대화와 판독 결과를 연결하며, 인공지능(AI)이 먼저 정리한 결과를 직원이 다시 확인·수정·거부·승인하는 흐름을 제공합니다.

## 현재 제공하는 기능

### 일반 채팅과 개인별 MESIL AI 도움방

- 일반 채팅방에서 메시지·첨부·검색·음성/영상통화를 사용합니다.
- `MESIL AI 도움방`은 로그인한 직원마다 하나씩 제공되는 개인 대화방입니다. 다른 직원은 그 방과 메시지를 열람할 수 없습니다.
- 일반 업무 질문은 내부 기록을 임의로 붙이지 않고 답하며, 특정 어르신 기록 질문은 현재 직원이 볼 수 있는 일반방 기록만 검색합니다.
- 기록을 사용한 답변에는 원문 근거를 표시하고, 근거가 부족하면 추측하지 않습니다.
- AI 답변은 진단·투약·처치·위험평가나 공식 기록을 자동 확정하지 않습니다.

### 검색 결과 AI 요약

- 검색 결과의 관찰, 인계, 확인, 후속조치와 결과 흐름을 근거와 함께 요약합니다.
- 관리자가 승인된 로컬 모델을 선택하며, 실제 사용 모델은 각 요청 결과로 확인합니다.
- 2026-09-15 공개 서비스 점검에서는 저장된 선택값과 실제 응답 모델이 일치했습니다.
- 넓은 검색(예: 40건)에서는 엄격한 대상자·근거 검증이 통과하지 못하면 근거를 유지한 규칙 기반 안전 요약으로 대체될 수 있습니다. 따라서 모든 40건 이상 검색이 검증된 AI 요약으로 끝난다고 주장하지 않습니다.

### 붙여넣기와 첨부

- 입력창에서 `Ctrl+V`로 일반 텍스트를 현재 커서 위치에 평문으로 붙여넣습니다.
- 브라우저가 제공하는 이미지·파일은 기존 첨부 대기목록에 추가됩니다.
- 붙여넣기만으로 서버에 전송하지 않으며, 사용자가 미리보기와 파일명을 확인한 뒤 `보내기`를 눌러야 업로드됩니다.
- 파일 선택과 붙여넣기는 같은 형식·크기·개수 제한을 사용합니다.

### OCR·VL·STT

- OCR(광학 문자 인식)과 VL(이미지 내용을 함께 이해하는 시각-언어 모델)로 사진·문서의 글자와 내용을 판독할 수 있습니다.
- STT(음성 인식)로 음성을 받아쓰기할 수 있습니다.
- 원본 첨부는 보존되고, 판독 실패나 미완료 상태를 성공처럼 표시하지 않습니다.
- AI 도움방은 완료된 판독 결과만 사용하며, 판독 전·실패 첨부를 읽었다고 주장하지 않습니다.

### 통화와 기록 검토

- 데스크톱과 모바일 화면에서 음성·영상통화를 지원합니다.
- 기록 검토 화면에서 원본 이미지와 판독문을 비교하고, 어르신 연결과 기록 초안을 사람이 수정·거부·승인할 수 있습니다.
- 확정 기록이나 외부 시스템 전송은 사람의 최종 검토 없이 자동 실행되지 않습니다.

## 개인정보와 AI 처리 경계

- 기본 AI 경로는 승인된 내부 Ollama 모델입니다. 실제 개인정보를 외부 AI로 자동 전환하지 않습니다.
- 권한 검사는 방 회원권과 조직 범위를 기준으로 하며, AI 답변 직전에도 근거 접근 범위를 다시 확인합니다.
- AI 결과는 제안 또는 초안입니다. 원문 확인과 최종 판단의 책임은 사람에게 있습니다.
- 이 구조는 위험을 줄이기 위한 기술적 경계이며, 모든 개인정보가 자동으로 완전 비식별 처리된다는 보장은 아닙니다.

## Chat과 Talk의 구분

- Chat과 Talk는 별도 서비스이며 컨테이너·데이터베이스·첨부·세션·설정을 분리합니다.
- 두 서비스는 서버의 GPU/Ollama 자원을 공유할 수 있지만, Chat의 모델 선택이 Talk 설정을 변경하지 않습니다.
- Chat은 Talk용 APK를 GitHub 또는 `/downloads`에서 제공하지 않습니다. 모바일에서는 브라우저 또는 PWA(홈 화면에 설치하는 웹앱)로 접속합니다.

## 설치와 실행

제3자 설치 절차와 필요한 도구는 [공개 설치 안내](docs/PUBLIC_INSTALL.md)를 따르세요.

1. 이 저장소를 복제합니다.
2. 프로젝트 루트의 `.env.example`을 `.env`로 복사합니다.
3. 예시 값을 새 비밀번호와 로컬 환경값으로 바꿉니다.
4. 설치 안내의 Docker Compose 순서로 기동합니다.
5. health와 로그인 응답을 확인합니다.

실제 `.env`, 데이터베이스, uploads, backups, logs, APK와 운영 증거는 공개 저장소에 포함하지 않습니다.

2026-09-15 기준 공개 서비스에서 합성 계정과 합성 기록으로 다음을 확인했습니다.

- 로그인, 일반 채팅방, WebSocket 실시간 연결

- `Ctrl+V` 텍스트·이미지 첨부 대기목록
