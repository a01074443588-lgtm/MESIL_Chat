# 가명 손글씨 표본 OCR 검증

검증일: 2026-07-28

## 검증 목적

가명 어르신 업무기록 5장, 총 25건을 이용하여 현재 로컬 OCR의 이름·숫자
판독 정확도와 긴 세로 사진 분할 판독의 중복 문제를 확인했다.

원본 이미지는 프로젝트와 Git 저장소에 복사하지 않았다. 검증 결과 JSON과
진행 로그는 `output/ocr_samples` 아래의 Git 제외 경로에만 저장했다.

## 시험 환경

- OCR 제공자: 로컬 Ollama
- 모델: `qwen3-vl:8b-instruct`
- 이미지 처리: 세로 사진을 3개 겹침 구간으로 나누어 판독
- 자동 교정: 사용하지 않음
- 비교 기준: 사용자가 제공한 가명 원문

## 개선 내용

겹쳐 판독한 앞 구간의 끝과 다음 구간의 시작이 줄 단위로 완전히 같을 때만
한 번으로 합치도록 변경했다. 띄어쓰기만 다른 완전 동일 줄도 같은 줄로
취급한다.

비슷하지만 다른 문장, 같은 문장이 떨어져 다시 등장한 경우, 이름·시간·숫자·
약·신체 부위·사건 내용은 자동으로 합치거나 고치지 않는다.

OCR 지시문은 실제로 보이는 한글과 숫자를 위에서 아래로 한 번씩 옮기고,
추측·교정·설명을 하지 않도록 명확히 했다.

## 남은 오류와 처리 원칙

다음과 같은 문맥 오류는 여전히 발생했다.

- `속이 답답하다`를 `속이 담담하다`로 판독
- `손등을 자꾸 긁으셔서`를 `손등을 자꾸 굽으셔서`로 판독
- `낮 동안`을 `낫 동안`으로 판독
- `쿠션 받쳐드림`을 `쿠션 발쳐드림`으로 판독
- `다소 묽은 양상`을 `다소 묶은 양상` 또는 `다소 붉은 양상`으로 판독

이 오류는 장기요양 기록의 의미를 바꿀 수 있으므로 AI가 자동 확정하지 않는다.
업무함에서 원문 이미지, OCR 원문, 과거 확정 이력에 따른 교정 후보를 함께
보여주고 담당자가 원문 유지·후보 적용·직접 수정·확인 필요 중 하나를 선택한다.

담당자가 확정한 결과만 교정 이력으로 추가 저장하고, 다음에 같은 오인이
나타났을 때 후보 점수에 반영한다.

## 재현 방법

1. 외부 가명 표본 경로를 `output/ocr_samples/evaluate_samples.py`의 시험
   목록에만 지정한다.
2. 프로젝트의 백엔드 가상환경에서 스크립트를 실행한다.
3. `output/ocr_samples/current_ocr_results.json`에서 식별번호, 숫자,
   유사도, 판독시간을 확인한다.
4. 결과 파일과 표본 이미지는 커밋하지 않는다.

## 결론

이번 변경으로 세로 사진 분할에 따른 명확한 중복은 제거했고 이름·숫자 정확도는
유지했다. 현재 OCR은 기록 초안을 만드는 용도로 사용할 수 있지만, 의미가 중요한
문구는 담당자 확인 없이 공식 기록으로 전환하면 안 된다.
