# 메실챗 심사위원 체험 안내

심사위원 전용 공개 주소: `https://chat.silvermedical.kr/reviewer`

> 아이디와 비밀번호를 복사하지 않아도 됩니다. 로그인 화면에서
> `요양보호사로 체험하기` 또는 `사회복지사로 체험하기`를 선택합니다.
> 관리자·개발자 런처 권한은 제공하지 않습니다.

일반 직원은 기존 주소 `https://chat.silvermedical.kr/`에서 기존 방식으로
로그인합니다. 심사위원 체험 화면은 일반 직원 로그인 화면을 대체하지 않습니다.

## 1. 무엇을 보는 프로토타입인가요?

메실챗의 최종 결과는 직원 채팅 자체가 아닙니다.

> **대화는 입력이고, 돌봄 브리핑이 결과입니다.**

직원이 남긴 짧은 채팅·음성·손글씨·사진을 어르신별로 모아 다음을 보여줍니다.

1. 오늘 평소와 달라진 어르신
2. 먼저 확인해야 하는 이유
3. 이미 한 일과 아직 확인할 일
4. 원문 근거와 기록 활용 후보

AI는 진단이나 공식 기록을 확정하지 않습니다. 사람이 원문을 확인할 수 있도록
근거를 연결합니다.

## 2. 제공하는 역할

| 역할 | 체험 목적 |
|---|---|
| 요양보호사 체험 | 가명 현장보고·첨부자료·읽음·답글 확인 |
| 사회복지사 체험 | AI 돌봄 브리핑·원문 근거·기록 활용 후보 확인 |
| 실시간 확인용 보조 역할 | 두 사용자 사이의 실시간 전달을 확인할 때만 사용 |

기본 화면에는 두 개의 큰 역할 버튼만 표시합니다. 실시간 확인용 보조 역할은
상세 영역에 두어 첫 체험 화면을 복잡하게 만들지 않습니다.

## 3. 역할 기반 3분 체험

### 0~30초 — 핵심 결과 찾기

1. `사회복지사로 체험하기`를 선택합니다.
2. 자동으로 열린 `AI 돌봄 브리핑`을 확인합니다.
3. `먼저 확인할 어르신`에서 가명 어르신 한 명을 봅니다.

기대 결과:

- 일반 채팅을 모두 읽지 않아도 먼저 확인할 대상과 이유가 보입니다.
- 제품의 결과물이 채팅이 아니라 돌봄 브리핑임을 알 수 있습니다.

### 30~90초 — 한 사건의 원문 근거 확인

1. 어르신 카드에서 `무엇이 달라졌나`를 봅니다.
2. `이미 한 일`과 `아직 확인할 일`을 구분합니다.
3. `근거 대화 보기`를 눌러 같은 자리에서 원문을 펼칩니다.
4. `기록 활용 후보`가 공식 기록 완료가 아닌 활용 가능성 표시임을 확인합니다.

기대 결과:

- AI 문장을 그대로 믿게 하지 않고 원문으로 돌아갈 수 있습니다.
- 해결된 조치와 남은 확인이 구분됩니다.

### 90~150초 — 필요한 근거만 정리

1. 기록별 모아보기에서 간호 관련 기록 후보를 엽니다.
2. 필요한 어르신과 근거만 선택합니다.
3. `선택 대화 AI 정리`를 누릅니다.
4. 결과의 대상과 근거번호를 확인합니다.

기대 결과:

- 선택하지 않은 다른 어르신의 사건이 섞이지 않습니다.
- 결과가 공식 기록으로 자동 확정되지 않습니다.

### 150~180초 — 입력과 실시간 전달

1. `요양보호사로 체험하기`를 선택하고 짧은 가명 보고를 전송합니다.
2. 상세 영역의 실시간 확인용 보조 역할에서 같은 방 메시지를 확인합니다.
3. 메시지 옆 읽음 수를 보고, 상세에서 답글을 남깁니다.

기대 결과:

- 현장 직원은 별도 복잡한 보고서를 먼저 작성하지 않고 평소 대화 방식으로
  입력합니다.
- 입력 원문은 이후 브리핑의 근거로 남습니다.

## 4. 10초·30초·90초 확인 질문

### 10초

- 오늘 먼저 볼 어르신은 누구인가요?
- 왜 확인해야 하나요?
- 이미 한 일과 남은 일은 무엇인가요?

### 30초

- 일반 채팅앱과 무엇이 다른가요?
- AI는 무엇을 하고, 사람은 무엇을 확인하나요?
- 원문 근거는 어디에서 여나요?
- 어떤 기록에 활용할 수 있는지 어디에서 보나요?

### 90초

- 먼저 확인할 어르신을 찾았나요?
- 근거 대화를 같은 자리에서 펼쳤나요?
- 기록 활용 후보를 찾았나요?
- 필요한 근거만 AI로 정리했나요?

## 5. 문제가 생겼을 때의 대체 절차

별도 시연 영상은 이번 제출 패키지에 포함하지 않습니다. 공개주소 직접 체험을
기본으로 하며, 문제가 생기면 다음 순서로 확인합니다.

1. 네트워크 연결을 확인하고 심사위원 전용 공개 주소를 한 번 새로고침합니다.
2. 이전 화면이 남아 있으면 브라우저 또는 설치 앱을 완전히 닫고 다시 엽니다.
3. 역할 버튼이 동작하지 않으면 체험 가능 기간이 끝나지 않았는지 제출 담당자에게
   확인합니다.
4. 한 역할만 문제가 있으면 나머지 역할로 돌봄 브리핑과 근거 확인을 먼저
   체험합니다.
5. 공개 서비스 자체가 열리지 않으면 제출 담당자가 내부 상태·게이트웨이·터널을
   복구한 뒤 같은 공개 주소에서 다시 확인합니다.

비밀번호, 쿠키, 관리자 화면, 개발자 런처 화면을 캡처하거나 공개 문서에 남기지
않습니다.

## 6. 체험 중 주의사항

- 심사위원 체험은 기간이 정해진 가명 프로토타입 전용 기능입니다.
- 모든 어르신과 직원 이름은 가명입니다.
- 실제 개인정보를 입력하지 않습니다.
- 체험 중 작성한 가명 시험 메시지는 지정 심사방에 저장되며 다른 심사위원에게도
  보일 수 있습니다. 심사 종료 전 자동 삭제되지는 않습니다.
- `기록 활용 후보`는 공식 기록 완료를 뜻하지 않습니다.
- AI 결과는 진단, 공식 평가점수, 공식 기록 확정이 아닙니다.
- 가명 고정 회귀시험 결과를 실제 현장 정확도나 사고 예방 효과로 확대해 해석하지
  않습니다.
- 실제 개인정보 운영을 시작하기 전 심사위원 체험을 반드시 비활성화합니다.

> 메실챗은 일반 채팅앱이 아니라, 흩어진 현장 대화를 어르신별 확인 업무와 기록
> 활용 후보로 바꾸고 원문 근거까지 보여주는 AI 돌봄 브리핑 도구입니다.

저장소에 남기지 않습니다.

## 9. 역할을 여러 번 바꾸어 체험하는 경우

  화면으로 이동합니다.
- AI 돌봄 브리핑이 열려 있으면 우측 상단 `X`로 브리핑을 닫은 뒤
  `체험 선택으로 돌아가기`를 누릅니다.
- 요양보호사와 사회복지사 역할을 반복해서 바꿔도 새 세션을 계속 만들지

- 일반 직원 계정으로 로그인하려면 역할 선택 화면 아래의 `직원 로그인으로
  돌아가기`를 누릅니다. 이때 심사 세션이 명시적으로 종료됩니다.
- 이전 오류 화면이 브라우저에 남아 있으면
  `https://chat.silvermedical.kr/reviewer`를 새로 열거나 한 번 새로고침한 뒤
