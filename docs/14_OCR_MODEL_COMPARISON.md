# 손글씨 OCR 모델 예비 비교

기준일: 2026-07-26

## 목적과 자료 경계

실버메디컬 현장 손글씨 보고서 사진을 채팅으로 먼저 보낸 뒤, 업무함에서 여러 어르신과 내용을 분류하기 위한 1차 글자판독 모델을 비교했다. 사용자가 제공한 사진 12장은 외부 서비스로 전송하지 않았고 프로젝트에도 복사하지 않았다. 모델 입력은 로컬 읽기 전용 경로를 사용했으며, 판독 산출물은 Git 제외 `output`에만 저장했다.

정답 전사본이 없으므로 이번 결과는 문자 오류율(CER) 순위가 아니라 다음 항목을 본 예비 적합성 판정이다.

- 한국어 손글씨 서술문의 보존 정도
- 여러 이름과 시간·숫자의 누락 정도
- 빈 결과와 반복 결과 발생 여부
- 현재 PC에서의 처리시간과 GPU 사용량

## 비교 환경

- GPU: NVIDIA RTX 5080 16GB
- 현재 주 판독: Ollama `qwen3-vl:8b-instruct`, 세로 사진 3구간
- 비교 모델: NVIDIA Nemotron OCR v2 공식 Docker 실행
- 원본 수: 손글씨 사진 12장
- 개인정보 보호: 외부 API 미사용

## 결과

| 항목 | Qwen3-VL 8B instruct | Nemotron OCR v2 |
|---|---|---|
| 처리 방식 | 세로 사진 3구간을 각각 판독 후 결합 | 공식 검출·인식·관계 모델 |
| 준비 후 장당 시간 | 완료 장 약 11.98~16.33초 | 약 0.11~0.14초 |
| 이번 12장 완료 | 10장, 2장 반복 방지로 실패 | 12장 실행, 2장은 사실상 빈 결과 |
| 한국어 손글씨 서술문 | 상대적으로 더 많이 보존 | 심한 누락과 오인식 |
| 이름·숫자 | 오인식이 있어 원본 대조 필수 | 이번 표본에서는 단독 사용 불가 |
| GPU 메모리 | 기존 로컬 운영 범위 | 최대 Torch CUDA 할당 약 1.85GB |
| 현재 결정 | 주 판독 초안 유지 | 빠른 보조 판독 후보 |

Nemotron OCR v2의 공식 자료는 한국어 지원, 손글씨 학습자료 포함, 구조화된 글자·위치·신뢰도 출력을 설명한다. 그러나 공식 한국어 수치는 합성 문서 기준이므로 이번 현장 손글씨 사진의 품질을 보장하지 않는다.

- NVIDIA 실행 페이지: https://build.nvidia.com/nvidia/nemotron-ocr-v2
- NVIDIA 공식 모델 카드: https://huggingface.co/nvidia/nemotron-ocr-v2

## 결정

1. 현재 보고서 이미지의 주 판독 초안은 `qwen3-vl:8b-instruct` 3구간 방식을 유지한다.
2. 판독 결과는 공식 사실이 아니라 담당자가 원본과 대조하는 후보문이다.
3. Nemotron OCR v2는 속도가 필요한 인쇄물 구조·보조 신호 비교에만 남긴다.
4. 두 모델의 결과를 자동으로 섞어 공식 기록으로 만들지 않는다.
5. 최종 모델 선정은 가명 자료와 정답 전사본 30~50장을 준비해 이름·숫자·날짜·투약표현 오류를 별도로 집계한 뒤 한다.

## 다중 어르신 처리

- 작성자가 어르신을 직접 고르면 해당 연결은 즉시 확인 상태가 된다.
- 선택하지 않아도 일반 채팅과 담당자 확인 판독문에서 활성 어르신의 정확한 이름을 여러 개 찾는다.
- 찾은 이름은 자동 확정하지 않고 `확인 후보`로 업무함에 표시한다.
- 남은 후보를 모두 `맞음` 또는 `제외` 처리하기 전에는 AI 시험 제안을 만들지 않는다.
- 동명이인, 별칭, 불완전한 이름은 자동 연결하지 않고 담당자가 직접 확인한다.

## 다음 비교 조건

정답 전사본이 있는 가명 손글씨 30~50장을 같은 해상도·같은 전처리로 준비한다. 문자 오류율뿐 아니라 다음 필드의 정확도를 따로 계산한다.

- 어르신 식별명
- 날짜와 시각
- 체온·혈압·복약량 등 숫자
- 낙상·통증·상처·투약 등 위험 표현
- 한 장에 등장한 어르신 수
