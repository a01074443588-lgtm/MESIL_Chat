# 초기 범위·제외범위·단계계획

## 구현 범위

- 일반 채팅과 공지
- 가상 어르신 선택, 사진, 읽은 직원, 댓글, 업무자료 처리함
- 조직·직원·방·멤버십·메시지·세션·감사기록
- 자동 채팅방과 관리자 지정방 생성·참여자 변경·기록보존 종료
- 읽지 않은 수와 최근 메시지
- 모바일·PWA
- 백업·복원·컨테이너 실행

## 제외 범위

- 음성 녹음·인식
- 실제 외부 AI 판독·자동 구조화
- 어르신 보고 취합
- 인수인계 자동생성
- 기존 SMCODI·관찰보고·케어포 연결
- 실제 도메인 연결
- 파일전송·통화·복잡한 오프라인 동기화

## 단계계획

1. **현재 완료:** 핵심 세로형 채팅 흐름
2. **다음:** 실패복구·감사조회·세션 관리 보강
3. **현재 완료:** 독립 PostgreSQL과 SMCODI 호환 데이터 경계
4. **준비 완료:** SilverHome용 HTTPS 설정·운영 비밀값 점검·PWA 브라우저 검증
   - 실제 서버 생성, DNS 연결, 실제 휴대전화 설치는 별도 승인 단계
5. 다중 백엔드용 Redis 이벤트 전달
6. **현재 완료:** 원문·시험 제안·담당자 확정 데이터 계약
7. **현재 완료:** 확정자료의 서류 종류별 읽기 전용 후보 대시보드
8. 별도 승인 후 실제 AI 제공자와 인수인계 변환 API 설계

각 단계는 이전 단계의 자동화·브라우저 시험이 통과된 뒤 진행한다.
