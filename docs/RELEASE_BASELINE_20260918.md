## 공개 패키지와 운영 이미지의 차이

- 설치용 Dockerfile·Compose·`.env.example`은 기존 공개 검증용 구성입니다. 운영 호스트·DB·네트워크·비밀키 설정을 복사하지 않습니다.
- 로고·아이콘과 알림음은 이전 공개본의 검토된 자원을 유지했습니다. 알림음 WAV는 운영 이미지의 파일과 다르며 실제 직원 음성을 새로 추출하거나 공개하지 않았습니다.
- 모델 파일, 실제 업무자료, 첨부·음성·사진, DB dump, 백업·로그, 세션, API 키, VAPID 키, 브라우저 인증 상태, APK·서명키는 포함하지 않습니다.
- 로컬 설치는 새 DB로 시작합니다. 별도 내부 AI·STT 연결과 장비가 필요합니다. 운영 모델·서버 성능·동시 사용 환경까지 재현하는 패키지는 아닙니다.
- 기존 공개 시험과 설치 문서는 기준 소스에서 유지하고, 기간 해석·답변 대상 표시·전체 대상 누락의 직접 관련 시험을 추가했습니다. 내부 결과 로그나 과거 성공값을 시험자료로 넣지 않습니다.
