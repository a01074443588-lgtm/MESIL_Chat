# PRD

## 사용자

- 관리자: 조직정보, 직원계정, 자동배정, 지정방, 퇴사 처리를 관리한다.
- 재직 직원: 허용된 채팅방만 보고 일반 메시지를 작성한다.

## 핵심 문제

일반 업무대화와 공지를 모바일에서 빠르게 공유하되, 소속과 재직상태가 바뀌면 접근권한이 즉시 반영되어야 한다.

## 1단계 필수 기능

1. 관리자·직원 로그인
2. 사업부·부서·직종·층·팀 데이터 관리
3. 직원 등록·수정·퇴사
4. 전체방과 조직별 자동방
5. 관리자가 선택한 직원 지정방
6. 실시간 텍스트 메시지와 공지
7. 작성자·작성시간·읽지 않은 메시지
8. 모바일 화면과 PWA
9. 퇴사자의 세션·WebSocket·재로그인 차단

## 성공기준

- 직원은 활성 멤버십이 없는 방의 API를 직접 호출해도 `403`을 받는다.
- 소속 변경 후 이전 자동방의 활성 멤버십이 종료된다.
- 퇴사 처리 트랜잭션에서 활성 세션과 멤버십을 모두 닫고, 열린 연결에 `force_logout`을 보낸다.
- 서버 재시작 후 조직·직원·방·메시지가 유지된다.

## 비기능 요구

- 큰 터치영역, 단순 조작, 390px 모바일 화면 지원
- 비밀번호·세션 원문 DB 저장 금지
- 특정 PC 절대경로와 IP를 코드에 고정하지 않음
- 현재 PostgreSQL 자료를 새 서버로 백업·복원 가능하며 운영 전 HTTPS 적용
