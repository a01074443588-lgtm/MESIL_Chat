## 편집과 확인 범위

서로 다른 촬영 실행의 앞부분과 질문·근거 확인 부분을 연결한 편집본이며, 한 번의 연속 실행이나 모든 기능의 검증 결과가 아닙니다. 영상의 응답시간 표시는 해당 촬영 실행의 측정값이며 일반적인 응답속도를 보장하지 않습니다. 실제 현장 성과가 아닌 합성자료 시연입니다.

v3는 기존 촬영본을 재편집한 영상입니다. 시작 부분에 서비스 소개를 추가하고, 답변과 원문 확대 구간은 로딩이 끝난 화면을 사용했습니다. 마지막에는 AI 답변이 자동으로 공식 기록이 되지 않으며 직원이 원문을 확인하고 판단한다는 안내를 담았습니다. 이 편집을 위한 새 촬영·새 AI 요청은 없었습니다.

v3 공개 준비 시 75.00초 규격과 전체 영상 디코딩 오류가 없음을 확인했고, 7.5초 간격 화면 표본 10장을 살펴보았습니다. 표본에서 실제 이름·연락처·얼굴·로그인 비밀값은 관찰되지 않았습니다. 이는 모든 프레임에 대한 개인정보 자동 검증을 의미하지 않습니다. 오디오 스트림은 없습니다.
