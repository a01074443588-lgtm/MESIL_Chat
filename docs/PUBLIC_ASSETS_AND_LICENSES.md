# 공개 후보 자산과 의존성

## 포함 자산

- 브랜드 로고와 앱 아이콘 3개: 실버메디컬 브랜드 자산이며 인물 사진이 아닙니다. 실버메디컬복지센터 대표자가 MESIL Chat 공개 저장소 포함과 저장소 복제·빌드·실행·배포 화면 표시를 승인했습니다. 이 기록은 사용자의 권리자 진술과 공개 승인에 근거하며 계약서나 저작권 등록증을 직접 검토한 결과가 아닙니다. 정확한 파일 지문과 제한은 [브랜드 자산 이용 범위](../ASSET_LICENSES.md)를 확인합니다.
- 알림 WAV 1개: 기존 코드의 대체 알림 주파수 523.25/659.25/783.99Hz를 수학적으로 합성한 차임입니다. 사람 음성·녹음·외부 샘플이 없습니다. 기존 음성 태그는 재배포 출처 확인이 없어 제외했습니다. URL은 기존 코드 호환을 위해 유지하지만 내용은 음성이 아닙니다.
- Backend 시험 PDF 69개: 합성자료 생성기와 코드형 대상자 표기가 확인된 시험 문서입니다. 텍스트·속성의 로컬 명부 대조 0건, 내장 사진과 첨부파일 0건입니다. 실제 기관 문서나 현장 성과 자료로 사용하지 않습니다.

## 폰트

독립 TTF/OTF/WOFF 파일은 배포하지 않습니다. 웹은 시스템 글꼴을 사용합니다. 시험 PDF의 맑은 고딕 부분 포함은 문서 임베딩에 한정되며, 확인한 원본 글꼴의 fsType은 8(editable embedding)입니다. 앱용 글꼴 재배포 권한을 뜻하지 않습니다.

근거: [Microsoft 문서 글꼴 포함 안내](https://learn.microsoft.com/en-us/typography/fonts/font-faq#document-embedding).

## 소스와 의존성

프로젝트 소스의 적용 범위는 루트 LICENSE를 확인합니다. 브랜드와 제3자 자료에 일괄 적용하지 않습니다. Frontend는 package-lock.json, Backend는 uv.lock에 버전을 고정합니다. 의존성 자체와 모델 파일은 이 후보에 넣지 않습니다. 설치 시 해당 배포처에서 내려받으며 각 의존성의 라이선스를 따라야 합니다. 설치된 의존성의 라이선스 목록은 별도 검수 근거에 기록합니다.

모델 이름을 자유로운 재배포 허가로 해석하지 않습니다. 운영 사용자 정의 텍스트 모델의 upstream·변환 계보와 배포 권한은 확인되지 않았습니다. OCR/VL/STT 모델 또한 사용할 버전의 model card와 라이선스를 운영자가 확인해야 합니다. 이 소스 후보에는 모델 가중치나 API 키가 없습니다.

## 제외한 모바일 범위

mobile의 Java 파일은 웹과 네이티브 신호 계약을 설명하는 참조입니다. 완전한 Android 프로젝트나 APK 제작 도구가 아니며, 앱 배포·서명·Firebase 설정·실기기 식별자를 포함하지 않습니다.
