# 신규 설치 전용 공개본

이 소스는 기존 Chat DB를 업그레이드하는 배포물이 아닙니다. 2026-10-23 공개·배포 승인을
받았습니다. 같은 날 외부 포트 없는 임시 DB·API에서 빈 PostgreSQL
설치·재실행과 합성 자료 보존을 확인했습니다. 전체 Compose·브라우저 화면·백업 복원과
실제 기기 소리·알림 표시는 이 신규 설치 시험으로 검증하지 않았습니다.

## 대상과 제외

- 신규 설치용 빈 DB/스키마만 대상으로 합니다. 기존 데이터 연결·복사·변환은 하지 않습니다.
- 직원 직접 등록·수정·퇴사, 수동 서비스 배정과 일반 Chat 기능을 유지합니다.
- 카톡 연동 구현과 과거 직원 외부명부 자동 반영 구조는 포함하지 않습니다.
- 직원의 수동 배정에 필요한 계정 식별·근무기간 구조는 남습니다. 외부 수집 기능은 없습니다.
- 어르신 관련 기능은 이번 직원 기능 분리와 별개이며, 개인정보 검증이 추가로 필요합니다.
- 실제 계정·대화·첨부·환경파일·기기 구독·키를 포함하지 않습니다.

## DB 경계

기존 마이그레이션 이력 대신 독립 기준 `001_chat_public_20261022`를 사용합니다.
기존 DB에는 이 새 기준을 적용하거나 `stamp`, 초기화, 삭제, 복사하지 마세요.
기존 DB의 업그레이드에는 별도로 보존한 비공개 호환 소스와 원래 이력을 사용합니다.

새 기준은 ORM(코드의 데이터 구조)에서 생성한 고정 PostgreSQL DDL(테이블 생성문)과
확정 기록·AI 근거의 변경 방지 함수·트리거를 포함합니다. 격리된 실제 PostgreSQL에서
66개 앱 테이블과 버전 이력, 함수 2개·트리거 4개의 생성 및 이력 수정·삭제 차단을
확인했습니다. 이전 운영 구조와 완전한 동일성을 입증한 것은 아닙니다.

마이그레이션은 비어 있지 않은 대상, 다른 DB 버전 이력 및 `public` 검색 경로의
같은 이름 테이블 충돌을 먼저 차단합니다. 실제 앱 시작도 신규 기준의 식별값을
확인하며 테스트 환경 외 자동 테이블 생성은 금지합니다. `downgrade` 삭제는 차단합니다.

## 검증 범위와 남은 한계

1. 2026-10-23 시작 명령의 종료 신호 처리를 보완했습니다. 이전 명령의 20초 후 강제 종료를
   재현하고, 같은 합성 DB를 사용하는 수정 이미지에서 두 번 모두 약 1초 정상 종료와
   재실행 후 자료 보존을 확인했습니다. 전체 Compose 배포나 운영 Chat 적용은 아닙니다.
2. 이번 실제 HTTP 시험은 관리자 로그인·직원 등록/비밀번호 변경·방·대화·첨부 바이트·
   권한·읽음까지입니다. 전체 직원 업무와 전체 Compose/브라우저·기기 시험은 별도로 확인합니다.
3. 개인정보 패턴 후보 27건은 합성 시험값으로 분류했고 의존성 719개 버전·공개 자산 4개의 출처와 고지를 대조했습니다. 자유문장과 과거 Git 이력 전체의 개인정보·법적 적합성 인증은 아닙니다.
4. 기존 예시 Chat은 종전 DB 이력을 보존하는 별도 호환 경로로 적용합니다. 이 공개본의 빈 DB 기준으로 기존 자료를 변환하거나 복구하지 않습니다.

현재 검토 폴더의 상위 경로, 비공개 업그레이드 사본, 로그·복구 사본을 통째로
공개하지 마세요. 이 문서에 완료로 적지 않은 검증을 완료로 해석하지 마세요.
