# 모바일·PWA 설계

## 화면

- 720px 이하에서 채팅방 목록과 대화화면을 한 화면씩 전환
- 입력·버튼 최소높이 44~52px
- 안전영역(`safe-area-inset-bottom`) 반영
- 작성자·시간·공지 유형을 시각적으로 구분
- 390×844 브라우저 화면에서 목록 가독성 확인

## PWA 구성

- `public/mesil-chat.webmanifest`
- `public/mesil-chat-sw-v6.js`
- `public/offline.html`
- 192×192, 512×512 PNG 아이콘
- `display=standalone`, `start_url=/`, 앱 식별값 `/mesil-chat-app`

## 알림 방식

- 채팅 화면이 열려 있을 때: WebSocket으로 즉시 수신하고 약 0.82초 길이의 MESIL_Chat 전용 `메딕` 음성 태그를 재생한다.
- 화면이 꺼졌거나 앱이 백그라운드일 때: Web Push 알림으로 안드로이드 잠금화면에 알린다.
- 잠금화면에는 어르신명·직원명·방 이름·메시지 원문을 보내지 않고 `새 메시지가 도착했습니다.`만 표시한다.
- 잠금화면 알림음과 진동은 아이폰·안드로이드의 `MESIL_Chat` 알림 설정을 따른다. 웹앱이 이 시스템 음색을 첨부 음원으로 임의 변경할 수는 없다.
- 직원은 `알림 설정 → 휴대전화 알림 켜기`를 한 번 눌러 현재 로그인 기기를 등록한다.
- 구독은 로그인 세션과 연결한다. 로그아웃·세션 종료·퇴사 처리된 기기에는 더 이상 푸시를 보내지 않는다.
- 앱이 다시 활성화되면 대기 중 놓친 메시지를 다시 조회하고 오래된 실시간 연결을 교체한다.

## 검증

Chrome의 설치가능성 검사에서 컨테이너 주소 `http://localhost:8080`에 오류가 없었고, 매니페스트 오류 없음·서비스워커 제어 활성·아이콘 HTTP 200을 확인했다. 게이트웨이는 매니페스트를 `application/manifest+json`으로 응답한다.

390×844 실제 브라우저 화면에서 방 목록, 채팅방, 사진 미리보기, 어르신 선택, 파일·공지·업무지정, 메시지 입력과 보내기 버튼의 가독성과 터치영역을 확인했다. 알림 소리 설정도 같은 크기에서 확인했다. 캡처는 `output/playwright/mobile-room-list.png`, `mobile-chat-room.png`, `mobile-notification-settings.png`에 보관한다.

공개 주소 `https://chat.silvermedical.kr/`에서 서비스워커 v6, 푸시 알림 설정 화면, 매니페스트·192/512 아이콘 응답을 확인했다. 공개 화면에서 `휴대전화 알림 켜기`가 활성 상태로 표시되고, 전면·PC 알림음은 MESIL_Chat 전용 `메딕` 음성 태그를 사용한다.

## 제한

`localhost`는 브라우저가 안전한 주소로 예외 인정하지만 휴대전화에서 PC의 LAN IP로 접속한 HTTP 주소는 안전한 출처가 아니다. Web Push와 홈 화면 설치 시험은 HTTPS 공개 주소 `https://chat.silvermedical.kr/`에서 진행한다.

웹 푸시는 구현·공개 배포·자동시험까지 완료했지만 실제 잠금화면 도착과 시스템 알림음은 휴대전화에서 알림을 켠 뒤 물리기기로 최종 확인해야 한다. 현재 PC·Docker·인터넷·Cloudflare Tunnel 중 하나가 꺼지면 알림 서버도 중지된다.
