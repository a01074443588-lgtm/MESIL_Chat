# 프로젝트 개요

## 목적

SMCODI 채팅방은 실버메디컬 직원의 업무대화와 공지를 위한 독립 내부 서비스다. 현재 AI 챌린지용 관찰보고·인수인계 개발을 보호하면서, 향후 하나의 직원용 앱으로 통합할 수 있는 채팅 기반만 먼저 만든다.

## 독립 경계

- 작업경로: `D:\Projects\SMCODI_CHAT`
- 기존 `D:\Projects\SMCODI` 및 관찰보고·인수인계 코드·DB·문서와 연결하지 않음
- 실제 직원·어르신 개인정보를 사용하지 않음
- 공개 체험 주소 `https://chat.silvermedical.kr/`는 현재 PC의 독립 서비스에만 연결
- 공개 홈페이지와 기존 SMCODI 코드·DB·로그인은 변경하거나 공유하지 않음

## 현재 결과

관리자 로그인 → 가상 직원 등록 → 조직 배정 → 자동 채팅방 → 직원 로그인 → 실시간 대화 → 소속 변경 → 권한 갱신 → 퇴사 즉시 차단 흐름이 API 자동화 시험과 독립 브라우저 세션 시험에서 동작했다.

어르신을 선택한 채팅은 담당자 업무함에 즉시 나타난다. 원문은 수정 불가능한 스냅샷으로 보존되고, 외부 AI가 아닌 시험규칙 제안과 담당자가 확인한 확정 결과가 분리 저장된다.

## 기술구조

- 화면: React 19 기반 모바일 웹앱
- API: FastAPI
- 실시간: WebSocket
- 로그인: DB에 해시만 저장하는 불투명 세션 토큰과 HttpOnly 쿠키
- DB: 독립 PostgreSQL 17
- 스키마 변경: Alembic
- 호환 경계: SMCODI의 조직·직원·직종·어르신·StaffHub 명명과 UUID·시간대·JSONB 원칙 반영
- 재현 실행: Docker Compose와 Caddy

SMCODI의 데이터베이스를 직접 공유하거나 수정하지 않는다. 현재 채팅 DB에서 검증한 뒤 향후 API 또는 명시적 이전 작업으로 연결한다.
